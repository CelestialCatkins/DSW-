# DSW 容器工作区

给 AI 聊天页面装一个**能存文件的虚拟硬盘**。

装上之后，AI 不只是在聊天框里说话 —— 它可以真的在你的聊天页面里**建文件夹、写文件、读文件、改文件、删文件**，而且这些文件会一直留着，下次开新对话也能接着用。

支持的平台：DeepSeek、ChatGPT、Claude、Gemini、Copilot、Poe、Kimi、豆包、通义、元宝、Grok、Google AI Studio 等 **13 家 / 20 个域名**。

---

## 一、它解决什么问题

没有这个脚本时，你让 AI「把这段代码存成文件」，AI 只能把代码吐在聊天记录里：

- 复制粘贴半天，关掉页面就没了；
- 换个新对话，问它「刚才那个文件呢」，它不记得；
- 文件多了根本没法管理，删错一段就前功尽弃。

装上之后，AI 有了自己的硬盘。你跟它说「建个 `项目/src` 文件夹，把这段写进 `main.js`」，它就真的建好、写进去了。

## 二、功能一览

| 能力 | 说明 |
|---|---|
| **读写文件** | 建目录、写文件、追加、改其中几行、批量写多个文件 |
| **检索内容** | 全库搜索、找文件、比对两个文件差在哪 |
| **整理加工** | 排序、切分、合并、打包成 zip 发给你 |
| **安全网** | 每步都有撤销；写错了能整体回滚；删掉的东西进回收站 |
| **任务清单** | AI 可以维护一份计划清单，贴在输入框上方：避让附件区与工具栏，不遮面板，展开时内部滚动、底部按钮常驻 |
| **文件编辑器** | 点开文件直接改：撤销、重做、全选、复制、粘贴、保存；短按撤销退一步，长按撤销回到任意保存点；自动保存默认开 |
| **状态条** | 悬浮球旁显示进度和后台作业，最多露 3 条，多了滚动看；只是显示，不挡你点聊天 |
| **MCP 工具** | 可选：把支持 Streamable HTTP 的 MCP 服务（例如手机上的 NP Manager）接进来，让 AI 调用它开放的工具 |
| **跨对话记忆** | 文件不跟着对话走，换个新对话，文件还在 |
| **存哪儿你说了算** | 存在浏览器里、存进你自己的手机/电脑文件夹，都能选 |

**一共 34 个命令**，AI 会用，你不用记。

## 三、产品特色

**① 文件能落到你自己的手机文件夹里**

别人的脚本大多只能存在浏览器缓存里，一清缓存就没了。这个可以把文件按原样存进你指定的文件夹（比如 `/项目/src/app.js`），用手机自带的文件管理器直接能看到、能改、能备份。换手机、换浏览器也能拷过去。

**② 不给 AI 乱改的机会**

**写操作和危险操作（删除、上传、恢复、撤销、重做）只有写在「执行域」里才会执行**，域外的一律不生效 —— 就算 AI 在正文里随口写一句「顺便删掉 xx」，也删不掉。

（所谓「执行域」，就是 AI 专门用来下命令的那个代码块；写在别处的话，容器只当它是普通聊天文字，压根不理会。）

不想冒险的话，还能让它先「预演」一遍：`dry` 只校验、不落盘。

**③ 出错当场告诉你怎么改**

AI 写错了不会默默失败。每条命令都有回执，写错了会直接告诉你「你这样写不行，应该写成这样」，还附上候选路径。不用反复试错。

**④ 不会把 AI 撑爆**

AI 读大文件、读多了容易变笨。这个让 AI 用「令牌」指代具体某一处，改的时候只改那一行，不用把整个文件重新背一遍。

**⑤ 不怕把 AI 说漏**

AI 还没说完时，脚本不会插话打断它；等它真正说完了才执行。还会自动控制发消息的节奏，避免被平台判定为刷屏。

**⑥ 对话不「抢跑」**

第一次用的时候，脚本**不会**自己偷偷发消息。等你真的在新对话里输入内容、点了发送，协议说明才会和你的那句话合成一条发出去。

## 四、节奏器等待（发消息的“交通管制”）

### 它是干什么的

AI 每执行完一批命令，容器就要往聊天框发一条“回执”告诉它结果。如果一轮里发得又急又多，很容易被平台判定为发送频繁。

节奏器就是这层保护：它会数着上一轮发得密不密，自动决定这一条要不要**先等一等再发**。等多久不是随机的，是按固定档位来的：

| 你最近发得有多密 | 它等多久 |
|---|---|
| 很松（1 分钟 ≤2 条） | 3 秒 |
| 1 分钟 ≥3 条 | 5 秒 |
| 1 分钟 ≥4 条 | 8 秒 |
| 1 分钟 ≥6 条 | 12 秒 |
| 1 分钟 ≥8 条 | 20 秒 |
|   “太频繁”   | 30 秒 |

**注意：它只延迟发送** 

### 想关掉？两个地方都行

| 在哪儿 | 怎么关 |
|---|---|
| **首次运行的引导面板** | 「偏好」栏里有一项**节奏器等待**，关掉那个开关 |
| **随时** | 点悬浮球 → 右上角 **⋮** → **设置** → 找到「出站」分组 → 关闭**节奏器等待**那一项 |

两条路改的是同一个开关，在哪儿关都立刻生效，刷新页面也还在。

> 不建议关。除非你确认所在平台很宽松，否则关掉之后批量任务容易撞上限流。

## 五、怎么用（3 步）

1. **安装**：把 `dsw-vfs-2.16.0.user.js` 装进 Tampermonkey / 油猴 / 暴力猴，浏览器会自动识别。
2. **首次设置**：页面右下角会出现一个小圆球，点它打开工作区，按提示选一次「文件存哪儿」，完成。
3. **正常聊天**：在聊天框里说「建个 `笔记.md`，把今天的事写进去」就行，AI 会自己动手。

之后想看文件、撤销、设置，都在那个小圆球里。

## 七、MCP（可选，不配就完全不生效）

MCP（Model Context Protocol）让 AI 去调用**别的程序开放出来的工具**，比如你手机上 NP Manager 的 APK / 文件能力。不配服务时这一块完全不加载、不发任何请求，跟以前一模一样。

**只支持一种传输：Streamable HTTP**（含 SSE 流式响应）—— 一个 HTTP 地址即可，不是 stdio，也不是旧的「HTTP + SSE 双端点」。地址可以在局域网里，例如 `http://192.168.1.20:8787/mcp`。

### 怎么加

1. 点悬浮球 → 右上角 **⋮** → **设置** → 找到「MCP」分组。
2. 填**名称**（随便起，例如 `np`）和**地址**（服务端给的 Streamable HTTP 地址），点添加。
3. 点「列出工具」验证：能列出工具，说明连接、会话都通了（连不上会直接告诉你失败原因，不会闷着）。
4. **风险模式**三档，默认不选：
   - `部分自动` —— 只读工具自动执行，写入/危险工具先弹确认；
   - `全部自动` —— 都自动，但仍然留一条提示，不会静默；
   - `不自动允许` —— 每次都问。

   风险等级优先读服务自己声明的 `annotations`，没声明才查脚本内置的对照表。

### AI 怎么用

| 命令 | 作用 |
|---|---|
| `mcp status` / `mcp servers` | 看配置与连通状态 |
| `mcp tools [关键词] [page=N]` | 分页/搜索工具清单（工具很多时不会一次全灌给 AI） |
| `mcp schema <工具>` | 只看这一个工具的参数 |
| `mcp call <工具> <<<{…}>>>` | 调用；加 `nowait` 后台跑，用 `wait` / `jobs` / `kill` 收结果与终止 |
| `mcp risk allow\|partial\|never` | 切风险模式 |
| `mcp chain on\|off` | 允不允许 AI 连续调用 |

- 调用超过 30 秒会先回一个任务号，完成后自动汇报：**你输入框里有草稿就并进你的下一条消息**，空闲就单独发一条；失败也汇报。
- 只读或幂等的工具，90 秒内同样参数重复调用会自动跳过，不白跑。
- 诊断信息里的地址是打码的。

> MCP 能改你设备上的文件（比如装/删 APK），所以它和写命令同级：**只有写在执行域里才会执行**。

## 八、需要注意的

- 容器是**虚拟**的，和你电脑的真实硬盘无关，删了容器不会影响你的真实文件。
- 反过来，如果你把文件夹绑到了手机存储上，那边删了文件，容器里也会少 —— 两边是同一份。
- 危险操作（删除、上传、恢复、撤销、重做）必须由 AI 明确写出来才会执行，这是有意设的保险。
- DeepSeek 开了「深度思考」时，思考内容里的 ```dsw 不会被当成命令执行 —— 容器只认答案正文那块。页面正在重渲染（输入框被换掉）时，容器会先等一等再动手，最多等 6 秒，超时照做并留一条日志。
- 豆包：输入框、发送键、「停止生成」键都按页面自己的标记认（`chat_input_input` / `chat_input_send_button` / `chat_input_local_break_button`），所以「AI 还没说完就别插话、别抢发」在豆包上也真的生效；思考区（`message_thinking`）里的命令同样不执行。上传的文件走豆包的附件入口直接进聊天窗口。
- MCP 地址填的是局域网地址时，浏览器所在设备和那台服务要在同一网络里；脚本只连你亲手填的地址。
- 脚本本身不上传任何数据，文件只存在你选的介质里。
